A more current version of this pipeline with more annotations can be found at https://github.com/NateKorth/SAP

## Brief descritpion of Scripts:
# Calc_h2_ScreenBean.R
Calculates broad sense heritability of microbiome features from bean market class study with many samples

# MADP_Corlation.R
Identifies and visualizes correlated taxa from full MDP dataset

# MeasureLD.R
uses Tassel to measure LD between SNPs

# PlotMultiGWAS.R
1st attempt at plotting multiple GWAS outputs

# RunLDheatmap.R
Uses LDheatmap package to plot LD windows around loci of interest
